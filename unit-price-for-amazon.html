Privacy Policy — Unitify for Amazon

Last updated: May 2026

What this extension does

Unitify for Amazon reads Amazon search result pages in your browser and displays unit prices (price per kg, liter, count, etc.) as overlays on product cards and in a side panel. All processing happens locally on your device.

Data we collect

None. This extension does not collect, transmit, store externally, or sell any personal data or browsing history.

Local storage

The extension stores the following data only on your device using Chrome's local storage API:

  • Your display preferences (theme, density, sort order) — so they persist between sessions
  • A temporary search cache (last 30 minutes) — so the panel loads instantly when you reopen it

This data never leaves your device and can be cleared at any time from Chrome's extension settings.

Network requests

This extension makes no network requests of its own. It only reads pages you already have open in your browser. No data is sent to any server.

Permissions

The extension requests only the minimum permissions required:

  • activeTab — to read the current Amazon search page
  • storage — to save your preferences locally
  • sidePanel — to display the comparison panel
  • tabs — to detect when you navigate to a new page
  • Amazon domains — so the content script can run on Amazon pages

Third parties

No data is shared with any third party. The extension has no ads, no analytics, no telemetry.

Open source

The full source code is available at github.com/jojobry/amazon-unit-price-extension. You can verify exactly what the extension does.

Contact

If you have any questions, open an issue on GitHub or contact us through the Chrome Web Store listing.
